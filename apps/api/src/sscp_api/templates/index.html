Most of your dependency alerts cannot hurt you.

This platform reads your bill of materials, finds the functions each security fix changed upstream, and checks whether your code can actually reach them. You get the handful of findings that matter, with the call path as proof, and a signed document you can hand to anyone who asks.

How a verdict is reached

  1. Inventory

    Your lockfile becomes a bill of materials with exact versions and the dependency graph, so a transitive package can be traced to whatever pulled it in.

  2. Match

    Every component is matched against public advisory data by package URL and version range, not by name guessing.

  3. Reach

    For each advisory we diff the upstream fix commit to find the functions it changed, then search a call graph of your code and its dependencies for a path to them.

  4. Prove

    The result is written as an exploitability document, signed so that anyone can verify who produced it and that it has not been altered.
