Why this page is not Swagger

Swagger UI loads its JavaScript from a content delivery network, and this site sends script-src 'self': no third-party script runs here, by design, so the interactive explorer would be a blank page. There is no JavaScript anywhere in this interface (ADR-0011), which is why the reference is rendered on the server from the same schema the application serves.
