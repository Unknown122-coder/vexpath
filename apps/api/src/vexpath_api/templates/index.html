What it actually says

Note what the second one claims: present and traversed. Not "we didn't look" — the package was analysed and no path exists. That distinction is the whole point, and a finding nobody could check says so instead of passing.

How a verdict is reached

  1. Inventory

    Your lockfile becomes a bill of materials, so a transitive package can be traced to whatever pulled it in.

  2. Match

    Components are matched to advisories by package URL and version range, not by guessing at names.

  3. Reach

    Each advisory's fix commit is diffed to find the functions it changed, then a call graph of your code is searched for a path to them.

  4. Prove

    The result is an exploitability document, signed, so anyone can check who produced it and that it is unaltered.
