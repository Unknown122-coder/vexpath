What a count here does and does not mean

A function listed for an advisory is evidence about the fix, not a claim about your project. Whether any of it can run in your code depends on your call graph, which is what vexpath scan works out locally.

A large number of functions usually means the fix was part of a wider change, not that the package is especially dangerous. Where a release had to be diffed because the advisory named no commit, the symbols say tag_diff and are recorded at low confidence.
