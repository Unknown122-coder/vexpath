What this page is

An advisory tells you a package is vulnerable. It rarely tells you which functions the fix changed, and that is what decides whether your own code can reach the problem. These symbols are extracted by diffing each advisory's fix commit, and they are what the reachability analysis searches for.

A symbol listed here is evidence about the fix, not a claim about your project. Whether any of it can run in your code depends on your call graph.
