Where this runs

The gate runs in CI, not here. vexpath scan --policy evaluates it locally against the scan it just produced, so a build never depends on this platform being reachable. This page is for composing the expression and seeing what it would do before you commit it. 

vexpath scan . --policy '{{ expression }}'

Or put it in .vexpath.yml under policy:. True means the build fails, so a mistake tends towards a red build rather than a silently green one.
